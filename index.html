Installation & Setup

1

Run the Installer

Run UseAs_Setup_v2.1.exe. It installs:

  • ViGEmBus gamepad driver
  • Virtual monitor driver (usbmmidd, ticked by default)
  • Windows Firewall rules
2

Optional Drivers

Only needed for these features:

🎤 Microphone: VB-CABLE (the installer opens its website at the end).

📸 Webcam: OBS Studio (or Unity Capture).

3

Start & Connect

Open Use As Server and press START on the Dashboard.

Open the Use As app on your phone (same Wi-Fi) and tap your PC under Nearby Computers, or use Pair with QR.

Tip: the server's Setup tab checks drivers, firewall and network and has buttons to fix what's missing. Using the portable .exe? Install ViGEmBus yourself for the gamepad, and allow the app through the firewall when Windows asks.

1. Install the App

Download the .dmg for your Mac (Apple silicon or Intel), open it and drag Use As Server.app into Applications.

First launch: the app isn't signed by Apple yet. Right-click the app › Open › Open. On newer macOS, if there's no Open button, go to System Settings › Privacy & Security and click Open Anyway.

2. Permissions

In System Settings › Privacy & Security, turn Use As Server on under:

  • Accessibility – mouse, keyboard and gamepad keys.
  • Screen Recording – second screen.

macOS asks for the microphone (to record BlackHole for PC sound) and for Automation (to read what Music or Spotify is playing) the first time they're used.

3. Free Drivers (Optional Features)

  • 🎤 Microphone & 🔊 PC sound: install BlackHole 2ch. For the phone mic, choose BlackHole 2ch as the microphone in Zoom, Discord etc. To hear the Mac on the phone, set the Mac's sound Output to BlackHole 2ch (or a Multi-Output Device with BlackHole + your speakers, made in Audio MIDI Setup).
  • 📸 Webcam: install OBS Studio, open it and click Start Virtual Camera once to install its camera extension.
  • 🖥️ Extend the desktop: BetterDisplay can add a virtual display; without it the phone mirrors your screen.
Use an X11 (Xorg) session. Mouse, keyboard and the second screen use X11. Linux Mint uses X11 already; on Ubuntu and Fedora choose "… on Xorg" with the gear icon on the login screen.

Option A: .deb or .rpm (recommended)

Installs Use As Server with everything it needs (xdotool, pactl, playerctl, xclip, wmctrl, and v4l2loopback when your distro has it), adds it to the app menu, and sets up the gamepad and the webcam for you.

Ubuntu / Mint / Debian: double-click the .deb, or in its folder:

sudo apt install ./UseAsServer_v2.1_linux_amd64.deb

Fedora (for the webcam, enable RPM Fusion first):

sudo dnf install ./UseAsServer_v2.1_linux_x86_64.rpm

Then open Use As Server from the app menu, or run use-as-server. Restart once so the webcam (/dev/video10) and gamepad permission are active. Installing it also replaces the old 1.5 package and its Python setup.

Option B: Flatpak

Contains xdotool, xclip, wmctrl, playerctl and pactl. Install it from a terminal in the download folder (Linux Mint's Software Manager doesn't open .flatpak files):

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo flatpak install --user UseAsServer_v2.1_x86_64.flatpak flatpak run com.jeetstudio.UseAsServer

After installing, Use As Server is also in your app menu. The webcam and gamepad steps below are still needed: a Flatpak can't change system settings.

Option C: .tar.gz (any distribution)

1. Unpack and run (in the folder you downloaded to):

tar -xzf UseAsServer_v2.1_linux_x86_64.tar.gz chmod +x UseAsServer ./UseAsServer

2. Install the tools it uses (keys, media info, clipboard, window list):

Ubuntu / Mint / Debian

sudo apt install xdotool pulseaudio-utils playerctl xclip wmctrl

Fedora

sudo dnf install xdotool pulseaudio-utils playerctl xclip wmctrl

Arch / Manjaro

sudo pacman -S xdotool libpulse playerctl xclip wmctrl

Feature Setup

With the .deb or .rpm the webcam and gamepad are already set up; these steps are for the Flatpak and .tar.gz.

📸 Webcam Install v4l2loopback (sudo apt install v4l2loopback-dkms; Fedora: akmod-v4l2loopback from RPM Fusion; Arch: v4l2loopback-dkms), then load it as /dev/video10:
sudo modprobe v4l2loopback devices=1 video_nr=10 exclusive_caps=1 card_label="UseAs Cam"
Pick "UseAs Cam" in Zoom, Meet, OBS…
🎤 Microphone Automatic: the server creates a virtual microphone. In your app (or pavucontrol › Recording) choose "Monitor of UseAs_Virtual_Microphone".
🔊 PC sound Automatic: whatever plays on your default output is sent to the phone. No setup.
🎮 Gamepad Uses /dev/uinput. If games don't see it, allow access (until reboot):
sudo chmod 666 /dev/uinput
To keep it after reboots:
echo 'KERNEL=="uinput", MODE="0666"' | sudo tee /etc/udev/rules.d/99-uinput.rules sudo udevadm control --reload-rules && sudo udevadm trigger
🖥️ Second screen Mirrors your screen. Picking Monitor 2 tries to add a virtual 1920×1080 output with xrandr; this only works on some graphics drivers.
📋 Clipboard images Need xclip (included in the Flatpak).
🔥 Firewall If you use one, allow TCP 8080, UDP 8081 and TCP 8082. With ufw:
sudo ufw allow 8080/tcp && sudo ufw allow 8081/udp && sudo ufw allow 8082/tcp

How to Use Features

🖱️

Touchpad & Keyboard

Plug & Play
  • Move: slide one finger. Click: tap.
  • Right click: tap with two fingers, or tap the bottom-right corner.
  • Drag: hold one finger still for half a second, then move.
  • Two fingers: slide to scroll, pinch to zoom.
  • Three fingers: tap = middle click; swipe up = Task view, down = desktop, left/right = switch apps.
  • Keyboard: type in any language (voice typing works too), shortcut keys and your own key combos.

Mouse not working in games or Task Manager on Windows? Turn on Settings › Request admin rights in the server.

🖥️

Second Screen

Built-in (Windows)

Phone tab: Display. Pick a monitor and press start. H.264 streaming, up to 1080p at 60 fps.

  • Windows: pick a monitor the PC doesn't have (e.g. Monitor 2 on a one-screen PC) and a real extra monitor is added, sized to your phone. It's removed ~20 s after you stop.
  • macOS: mirrors your screen; use BetterDisplay to extend it.
  • Linux: mirrors your screen; a virtual output via xrandr works on some drivers.
  • For the smoothest picture use USB tethering (see Troubleshooting).
🎮

Gamepad

Auto
  • Windows: games see an Xbox 360 controller (ViGEmBus, installed by the installer). Up to 4 phones, each its own player (P1–P4), with rumble and tilt steering.
  • Linux: a virtual controller through uinput (see Linux setup).
  • macOS: no virtual controllers on Mac, so buttons are sent as keyboard keys (WASD and arrows).
🎤

Microphone

Driver Req

Phone tab: Microphone. Noise suppression and auto gain are in the app.

  • Windows: install VB-CABLE; in Zoom/Discord choose "CABLE Output" as the microphone.
  • macOS: install BlackHole 2ch; choose "BlackHole 2ch" as the microphone.
  • Linux: nothing to install; choose "Monitor of UseAs_Virtual_Microphone".
📹

Webcam

Driver Req

Phone tab: Camera. Camera Studio on the PC adds background blur or a picture behind you, mirror and brightness.

  • Windows: install OBS Studio and pick "OBS Virtual Camera" (or Unity Capture › "Unity Video Capture").
  • macOS: install OBS Studio, click "Start Virtual Camera" once, then pick "OBS Virtual Camera".
  • Linux: load v4l2loopback as /dev/video10 (see Linux setup) and pick "UseAs Cam".
🔊

PC Sound on the Phone

Built-in

Phone tab: Speaker, turn the switch on. The phone also shows the title, artist and cover of what's playing, with play/pause, next and previous.

  • Windows & Linux: works as is, no Stereo Mix or routing needed.
  • macOS: needs BlackHole 2ch as the sound output.
  • Hearing it twice? Mute the PC; the phone keeps playing. Lag: set the buffer to Low.
📂

Files & Clipboard

Easy
  • PC to phone: server's Sharing tab › Choose files…, drag files onto the window, or right-click a file › Send to › Use As (phone) (Windows) / Scripts › Send to phone (Use As) (Nautilus).
  • Phone to PC: share any file to "Send to PC", or use the app's Files tab. Files are saved in Downloads/UseAs_Received.
  • Browse the PC: the phone's PC tab opens the PC's files: download (folders as .zip), upload, rename, delete, and play photos, videos and music straight from the PC.
  • Clipboard: turn on Auto-sync: text, images and copied files go to the phone automatically. Phone to PC is sent while the app is open, or with "Send clipboard to PC" on the notification or Quick Settings tile. The last 20 texts are kept in a history.
🧰

PC Controls

Built-in
  • Lock, screen off, sleep, hibernate, restart, shut down and sign out, also on a timer ("sleep in 1 hour").
  • PC volume, per-app volume and screen brightness.
  • Open apps, switch, minimise or close windows.
  • Live CPU, memory, GPU (NVIDIA), disk, battery and network stats.

Per-app volume and the extra monitor are Windows only for now.

🎛️

Deck, Presenter & Notifications

Built-in
  • Deck: Stream-Deck-style buttons that open apps, files and websites, press key combos, type text or run commands.
  • Present: big Next/Previous, volume keys turn slides, laser pointer and a talk timer.
  • Notifications & calls: see the phone's notifications and calls on the PC, reply to messages and answer or decline calls.
  • Phone shortcuts: Quick Settings tiles and a home-screen widget (play/pause, mute, lock, touchpad).

Troubleshooting

⚠️ Phone can't find the PC (stuck on scanning)
  1. Phone and PC must be on the same Wi-Fi (or the phone's hotspot). Office, college and guest networks often block devices from seeing each other.
  2. Windows: open the server's Setup tab and use the Firewall fix, or search "Allow an app through Windows Firewall" and tick Private and Public for UseAsServer.exe.
  3. Linux: allow TCP 8080, UDP 8081 and TCP 8082 in your firewall.
  4. Use Pair with QR on the Dashboard, or type the address shown there (ws://…:8080) in the app.
  5. Android 17: allow "Nearby devices / local network" when the app asks.
🔌 Lag, stutter or disconnects: use USB tethering
  1. Connect the phone with a USB cable that carries data.
  2. On the phone: Settings › Network & internet › Hotspot & tethering › USB tethering: on.
  3. In the app, tap the PC labelled "USB Tethering". If Windows asks, choose a Private network.

Disconnects when the phone screen turns off? Set Use As to Unrestricted battery use in Android settings.

🎤 Microphone not working in Discord / Zoom

Select the virtual mic as the input device, not "Default": "CABLE Output" (Windows), "BlackHole 2ch" (macOS) or "Monitor of UseAs_Virtual_Microphone" (Linux).

🐧 Linux: webcam or gamepad not working
  • Webcam: the camera must be /dev/video10. Unload and load it again with video_nr=10:
    sudo modprobe -r v4l2loopback sudo modprobe v4l2loopback devices=1 video_nr=10 exclusive_caps=1 card_label="UseAs Cam"
  • Gamepad: run sudo chmod 666 /dev/uinput, then reconnect.
  • Mouse or second screen do nothing: log in with an X11 (Xorg) session, not Wayland.
🎮 Controller connected but not moving in game

Some games only accept an Xbox 360 controller: switch the layout to Xbox in the app and restart the game after connecting.

Windows: check the server's Setup tab shows ViGEmBus as installed (the portable version doesn't install it).

🍎 macOS: "app can't be opened" or mouse doesn't move

Right-click the app › Open, or System Settings › Privacy & Security › Open Anyway. Then make sure Use As Server is on under Accessibility and Screen Recording, and restart the app.

📝 Still stuck?

The Activity log on the server's Dashboard says what went wrong, and the How to use tab explains every feature. You can also open an issue on GitHub.
